# 📈 Indian Oil - Stock Market Analysis Dashboard (Power BI)

## 📌 Project Overview
This project is an interactive Power BI dashboard designed to analyze the historical stock market performance of **Indian Oil Corporation Limited (IOCL)**. The dashboard provides actionable insights into stock price movements, trading volumes, and trends over a specific period. 

## 🎯 Objectives
* To track the historical Open, High, Low, and Close (OHLC) prices of Indian Oil.
* To analyze trading volume patterns.
* To identify long-term trends and market volatility using Moving Averages.
* To create a user-friendly, interactive dashboard for quick data exploration.

## 🛠️ Tools & Technologies Used
*   **Data Visualization:** Microsoft Power BI
*   **Data Source:** Web
*   **Data Processing:** Power Query (for data cleaning and transformation)
*   **Calculations:** DAX (Data Analysis Expressions)

## 📊 Key Features of the Dashboard
*   **KPI Cards:** Displaying Current Price, 52-Week High/Low, and Total Volume.
*   **Trend Analysis:** Line charts showing stock closing prices over time.
*   **Candlestick Chart:** Visualizing Open, High, Low, and Close prices for detailed technical analysis.
*   **Volume Analysis:** Bar charts showing trading volume spikes.
*   **Interactive Slicers:** Filters for Date Range, Time Period (Monthly/Yearly).

## 💡 Key Insights Derived
*   Identified the highest trading volume days.
*   Observed a significant correlation between trading volume and price drops.
*   Analyzed the impact of market trends on IOCL stock.
